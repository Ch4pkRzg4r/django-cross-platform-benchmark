# Raw Archive Availability and Reconstruction
The complete campaign raw data (280 k6 JSON streams + 280 per-request CSV streams, ~90 MB each) are retained locally in verified multipart RAR sets (`raw data excel.part001–003.rar`, ~200 MB volumes; the JSON set in five volumes). Every file and every archive part has its SHA-256 in the adjacent manifests, with campaign-time modification stamps (16–17 May 2026). Reconstruction: place all volumes of a set together and run `7z t <part001>` then `7z x <part001>`; verify extracted files with `sha256sum -c` against `raw_files_sha256_manifest.csv`. Publication route (pending): GitHub Release assets or Zenodo DOI; no public raw-data URL is claimed until upload is tested.
