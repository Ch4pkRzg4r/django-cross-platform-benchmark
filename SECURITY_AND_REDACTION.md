# Security and Redaction

Content-level scans covered passwords, tokens, keys, connection strings, SAS signatures, subscription identifiers, private endpoints, personal data and histories. Findings and dispositions are logged privately. Public derivatives: `application/ecommerce/settings.PUBLIC.py` (SECRET_KEY and DB password → environment variables), `configuration/docker-compose-phase65.PUBLIC.yml` (all POSTGRES/DB passwords → `${…}` placeholders), `configuration/platforms.PUBLIC.json` (credential-shaped fields templated), `environment/pgbouncer_runtime_extract.txt` (auth lines redacted). Originals are preserved privately with their SHA-256 recorded; every derivative was re-scanned (zero real secrets) and structurally re-validated (JSON/YAML parse, Python byte-compile where applicable). One capture artefact is documented in ARTEFACT_PROVENANCE.md. No shell/PowerShell histories, invoices, payment data, Azure identifiers or personal files are included.
