# Figure asset status

The PNG assets and `figure_map.csv` already present in this directory are retained as **pre-v330 analytical/thesis provenance**. They must not be interpreted as the authoritative current final-thesis Chapter-4 figure map after the v330 calibration.

The current final-thesis map is:

`results/current-thesis/figure_map.csv`

The current dynamic figure carriers are generated by the validated v330 pipeline. The exact final publication rasters are retained in the controlled evidence package and their byte-identity hashes are recorded at:

`results/current-thesis/verification/PUBLISHED_FIGURE_SHA256_MANIFEST.csv`

This separation is intentional: changed analytical data regenerate changed dynamic figures, whereas the frozen publication rasters are never silently reused for a changed dataset.
