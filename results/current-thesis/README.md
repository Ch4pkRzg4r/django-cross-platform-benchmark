# Current final-thesis Chapter 4 artefacts

This directory is the **v330/current-thesis** artefact namespace. It is separate from the earlier `results/tables/` and `results/figures/` paths so that historical artefacts remain auditable instead of being silently overwritten.

- `tables/` contains the exact current-thesis Table 4.1–4.16 CSV mirrors produced by the validated v330 pipeline from the frozen controlled evidence inputs.
- `figure_map.csv` records the current Figure 4.1–4.12 + 4.13a–f captions and dynamic-output names.
- `backing-data/` contains the numerical carriers used by the current dynamic figures.
- `verification/` records the frozen-input calibration checks.

The exact publication raster assets are retained in the controlled evidence package; their hashes are recorded here. Dynamic figures are regenerated by v330 from analytical data. This separation prevents a changed-data run from being misrepresented by frozen publication images.
